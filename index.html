Key Skills & Expertise

Driving Business Outcomes with Data

Experiment Analysis. With DataSense LLC clients, I build semantic data models of their business. Then I pair frequentist and Bayesian modeling techniques to give clients coefficient estimations that are accepted in industry and academia, as well as estimate distributions that are often more useful in practical decision making.

Mechanistic Modeling. At Plenty, I built models using known biological patterns. Growth curves to forecast plant yield as a function of time helped terminate trials that were not on the projected curve. Light curves to find optimal protein fluorescence for plant yield were used to make inference about maximum intensity settings. Charting optimal vapor pressure as a function of grow system settings let the engineering team ensure the environment was optimal for plant growth.

Predictive Modeling. Used extreme gradient boosting models to predict product yields using environmental features and suggest correlations in complex environments. Top features driving model performance were used for planning research.

Custom Analytics and Analytics Dashboards. Developed interactive Streamlit apps and integrated BI tools like Lightdash on dbt models to provide stakeholders with self-guided data insights. Powered by dbt, a small team of one to two data folks could democratize data access for scientists. Complex analytics like plant growth models were presented to scientists through this visualization layer to inform decisions about which plants to use in grow systems.

Building Robust Data Platforms

Cloud Infrastructure & DevOps. Deployed applications using Docker, Kubernetes, ArgoCD, and AWS. This allowed Plenty to take advantage of open source tools and reduce licensing costs.

ELT Development. Built custom data replication pipelines using Airflow and Airbyte, streamlining data integration from novel sources to data warehouse Snowflake. This allowed Plenty to join batch and streaming data for improved feature engineering, ML model performance, and more comprehensive dashboards.

Data Transformation and Quality Control. Unified data sources and implemented business logic using the dbt framework to create data models for analytics. A GitOps approach to data management meant a small team could support the entire company using a hub-and-spokes model for data access.

Automated Deployments. Configured CI/CD pipelines using CircleCI and GitHub Actions. This reduced developer overhead by completing deployments, testing, and builds automatically.
